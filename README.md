- **六大學科全覆蓋**：收錄 **生物 (8篇)**、**理化 (12模組)**、**數學 (22單元)**、**社會 (9模組)**、**國文 (6模組)**、**英文 (6模組)** 共 **63 款** 互動特訓遊戲。

  - 🔊 **Web Audio API 合成音效**：答對/答錯/升級即時音效反饋。
- **即時搜尋與分科導覽**：首頁提供六大學科總部專屬入口與即時關鍵字搜尋過濾。
